# Dados estáticos

`municipios-br.json`: os 5.570 municípios brasileiros + Distrito Federal, no formato
`[código IBGE, nome, UF, latitude, longitude]` (coordenadas da sede, 4 casas decimais).
Usado para dar nome à região do usuário ("Missões perto de você · Olinda, PE") e para a
escolha manual de cidade, **sem chamar nenhum serviço externo**.

Fonte: [kelvins/municipios-brasileiros](https://github.com/kelvins/municipios-brasileiros)
(licença MIT, © 2016 Kelvin S. do Prado), a partir de dados do IBGE.
